# Store Rating System

A full-stack application for rating and reviewing stores, built with React, Node.js, and MongoDB.

## Features

- User authentication (login/signup)
- Store management
- Rating system
- Role-based access control (Admin/User)
- Responsive design with Tailwind CSS

## Tech Stack

- Frontend: React, TypeScript, Tailwind CSS
- Backend: Node.js, Express
- Database: MongoDB
- Authentication: JWT
